요코하마국립대 콘크리트 연구실용. 土木学会 コンクリート標準示方書 기준.

| 파일 | 무엇 | 실행 |
|---|---|---|
| `rc-capacity.html` | 단면 내력 계산기: 직사각형·T형·박스·원형, 2단 배근, 휨·전단·축 내력, M-N 상관도, 판정, M–φ 곡선, 사용성(균열폭·처짐), 전단 설계, 보 요소 FEM, 교육용 3D 비선형 FEM(변위/하중제어, 실시간 σ–ε, 회전·이동), 실험 CSV 비교, 케이스 JSON 저장/불러오기, HTML 보고서, 엑셀 계산서, 한/일/영 | https://claude.ai/artifact/F4ZSJfPxLxHixJozJtna7R |

## 연구실 배포 (스마트폰 앱 / 프로그램)

`python3 build_dist.py` 를 실행하면 `dist/` 에 배포용 파일이 생긴다 (ExcelJS 를 안에 넣은 단일 `index.html` 약 1.2 MB + PWA 매니페스트·서비스워커·아이콘). 아티팩트 전용 저장 기능 대신 브라우저 표준 다운로드를 쓰므로 어디서나 엑셀·JSON·보고서·PNG 저장이 된다. `rc-capacity-app.zip` 은 `dist/` 를 묶은 것.

세 가지 방법:
1. **파일로 전달 (가장 간단)**: `dist/index.html` 하나를 카톡·메일·USB 로 보낸다. PC 는 더블클릭, iPhone 은 파일 앱에서 열어 Safari 로, Android 는 Chrome 으로 열면 된다. 인터넷 없이도 동작 (글꼴만 기본 글꼴로 바뀜).
2. **웹 주소로 공유 + 홈 화면 앱 (추천)**: **https://hyonnnnnn.github.io/rc-capacity/** 에 올라가 있다 (저장소 https://github.com/hyonnnnnn/rc-capacity, `gh-pages` 브랜치 = `dist/`). 갱신: `python3 build_dist.py` → `git add -A && git commit -m "..." && git push` → `git subtree push --prefix dist origin gh-pages`. 연구실 사람들은 그 주소를 스마트폰으로 열고 "홈 화면에 추가"(iPhone: 공유 버튼 → 홈 화면에 추가, Android: 메뉴 → 앱 설치)를 누르면 앱 아이콘으로 실행되고, 서비스워커가 캐시해 두어 오프라인에서도 열린다. 새 버전은 `build_dist.py` 를 다시 돌려 파일을 올리면 다음 실행 때 자동 갱신.
3. **Claude 아티팩트 링크**: https://claude.ai/artifact/F4ZSJfPxLxHixJozJtna7R 를 Share 메뉴로 공유. 받는 사람도 Claude 계정이 필요.

### 컴퓨터 프로그램 (더블클릭 실행)

`app.py` 가 `dist/index.html` 을 시스템 웹뷰 창에 띄우는 데스크톱 프로그램이고, PyInstaller 로 묶으면 설치 없이 실행되는 파일이 된다. 저장 버튼은 OS 저장 대화상자로 연결됨.
- macOS: `sh build_app.sh` → `release/RC내력계산기.app` (이 Mac 에서 빌드·실행 확인, 약 25 MB). 서명이 없어서 처음 열 때 "확인되지 않은 개발자" 경고가 나오면 Finder 에서 우클릭 → 열기 (또는 터미널 `xattr -dr com.apple.quarantine "RC내력계산기.app"`).
- Windows: Python 을 설치한 뒤 `build_app.bat` 더블클릭 → `release\RC내력계산기.exe` (단일 파일, WebView2 런타임은 Windows 10/11 기본 포함). Windows 용은 Windows 에서 빌드해야 한다.
- 개발 중 바로 띄우기: `.venv/bin/python app.py`. 페이지를 고친 뒤에는 `python3 build_dist.py` 를 다시 실행.
- 묶음 안의 index.html 은 빌드 시점의 복사본이므로, 계산기를 갱신하면 프로그램도 다시 빌드해 배포.

주의: 3D FEM 은 스마트폰에서도 돌아가지만 "세밀" 요소 크기는 PC 를 권장. 서비스워커는 https(또는 localhost)에서만 등록된다.

## 복합 단면 (합성 재료 층)

입력의 "합성 재료 층" 표에 직사각형 층을 추가하면 RC 단면에 다른 재료를 합성한다 (중심 맞춤, 상연에서 y0·두께 t·폭 w, 콘크리트와 겹치면 치환). 직사각형·T형·박스에서 사용.
- 재료: 강재 플레이트 (fy, Es, 탄성–완전소성), UHPC (f′c, Ec; 압축 0.85f′c 평탄, 인장 ft = 0.23f′c^(2/3) 평탄 ~0.005), FRP 시트 (Ef, ffu; 인장만, 파단 후 0).
- 내력: 층이 있으면 Mu(정·부)와 M–N 상관도를 파이버 단면 해석(설계강도, 축력 11단계)으로 구함. 전단·βn·사용성·보 요소 해석(EI 는 환산단면)·엑셀 수식은 RC 식 그대로 (엑셀은 값만 기록).
- 3D FEM: 층 경계를 메시 분할점에 넣고 요소마다 재료 배정. 강재 요소는 von Mises 할선 소성, FRP 요소는 최대 주응력 > ffu 에서 파단, UHPC 는 자체 f′c·Ec·ft 의 손상 모델. 지압판은 지점·재하점에서 요소 크기 두께(얇은 층 위 콘크리트까지).
- 전단연결재 슬립 (3D, "강재 층 연결" 선택): 강재 층이 자기 절점을 갖고, 콘크리트와 같은 자리의 절점 쌍을 경계면 스프링으로 연결. x 방향은 Ollgaard (1971) 스터드 하중–슬립 Q = Pu(1 − e^(−0.709s))^0.4 의 할선강성(열당 본수/간격 × 분담길이, 열의 절점 쌍에 균등 분배, 갱신 감쇠 0.6), y·z 는 강결(들뜸 없음). 결과: 최대 슬립·Q 행, Q–s 실시간 그래프, 엑셀 열. Pu 를 아주 크게 주면 완전 합성과 같은 곡선 (검증: 1e6 kN → 단계별 하중 일치). 300×500 + 하연 강판, 3점 L 3 m: Pu 90 kN·간격 150·2본 → 7 mm 에서 300 kN (완전 합성 455), 슬립 0.8 mm; Pu 30·300·1본 → 슬립 2.4 mm, Q 가 Pu 에 수렴.
- 검증 (300×500 3-D22, γ = 1): 하연 강판 300×12 (fy 325) → Mu 589 kN·m (소성 손계산 ≈ 600), UHPC 상부 60 mm (f′c 150) → 175 (RC 166), FRP 300×1.2 (Ef 230 GPa, ffu 3000) → 421 (콘크리트 압괴 지배). 3D 3점 L 3 m 16 mm까지: 강판 489 kN(상승 중), FRP 315 (파단 후 175 로 낙하), UHPC 313 (RC 269).

## OpenSees 파이버 해석 (`beam_fiber_opensees.py`)

- 입력: 파일 맨 위 `P` 딕셔너리 (계산기와 같은 단위 mm, N/mm²). 직사각형은 `bf=b, hf=0`.
- 계산기에서 "입력 JSON 저장"으로 받은 파일을 인자로 주면 그 케이스로 실행: `.venv/bin/python beam_fiber_opensees.py Beam-01.json` (직사각형·T형만, 2단 배근은 가중평균 깊이로 합침).
- 결과 `out/beam_fiber.csv`는 계산기의 "실험 데이터 비교"에 그대로 올려 3D 해석·실험과 겹쳐 볼 수 있어요.
- 재료: Concrete02 (ε0 = 2f′c/Ec, ft = 0.23 f′ck^(2/3), 잔류 0.2f′c), Steel02 (변형경화 0.5%).
- 출력: `out/beam_fiber.csv`, `out/beam_fiber.png`. 콘솔에 초기강성(환산단면 보이론과 비교), 균열·항복·종국 하중, 등가응력블록 Mu와의 비.
- 검증값: 300×500 3-D22 직사각형 → 최대 170.5 kN (Mu 환산 165.8 kN, 비 1.03). T형 6-D22+2-D16 → 355.7 kN (비 1.06, ε′cu 미도달).

## Abaqus 모델 (`abaqus_rc_beam_inp.py`)

- C3D8R 콘크리트(향상 모래시계 제어) + T3D2 철근(주근·스터럽) `*EMBEDDED ELEMENT`.
- CDP: 팽창각 36°, 편심 0.1, fb0/fc0 1.16, K 0.667, 점성 0.0005. 압축 포물선+하강선, 인장 GFI(Gf = 73 fcm^0.18 N/m), 손상 변수 포함.
- 지점: 하연 절점선 핀·롤러. 재하: 상연 절점선 강제변위. 결과: 히스토리 RF2(재하점), U2(중앙 하연).
- 해석: `abaqus job=rc_beam input=out/rc_beam.inp cpus=4 interactive`
- 수렴이 안 되면: `viscosity`를 0.001로, `es`를 40으로, `target_disp`를 줄여 보세요.
- 이 폴더에서는 Abaqus를 실행하지 못했으므로 입력 파일 구조만 검증됨 (절점·요소 참조, 재료 표 단조성, 철근 위치).

## 3D 비선형 FEM 페이지 (`rc-beam-3d.html`)

브라우저 안에서 돌아가는 교육용 단순화 모델. 균열이 번지는 모습과 하중–처짐 곡선의 모양을 보는 용도. 정량 비교는 OpenSees나 Abaqus로.
- 테스트(30×6×2 메시): 최대하중 / 등가응력블록 Mu 환산 = 3점 1.27, 4점 1.09, 6-D22+2-D16 0.99, 40×8×4 3점 1.17.
- 주근 부착 선택: 완전 부착(기본) / 부착–슬립(양호·불량). 슬립 모드에서는 주근(인장·압축)이 열마다 전용 x 자유도를 가진 트러스가 되고, 각 절점이 fib MC2010 인발형 부착응력–슬립 법칙(τ = τmax(s/s1)^0.4 → 평탄 → s3 에서 0.4τmax; 양호 τmax 2.5√f′c, s1 1.0, s2 2.0 / 불량 1.25√f′c, 1.8, 3.6; s3 ≈ 0.5φ) 의 할선 스프링(둘레 × 분담길이)으로 콘크리트와 연결됨. 양단은 후크 정착으로 보고 강한 스프링. 스터럽은 완전 부착 그대로. 철근 자유도는 대역폭을 위해 해당 열의 콘크리트 절점 바로 뒤에 끼워 넣음(순열). 결과: 최대 슬립·부착응력 행, τ–s 실시간 그래프, 엑셀 단계 표의 슬립·τ 열.
  - 300×500 3-D22 3점(125 mm, 20 mm까지): 완전부착 1.22 → 양호 1.19 (최대 슬립 0.15 mm, τ 6.4), 불량 1.29 (슬립 0.42 mm, τ 3.8). 완전부착 결과는 슬립 코드 추가 전과 동일(순열 검증).
- 균열 모델 선택: 등방성 손상(기본) / 고정 균열 / 회전 균열. 회전 균열은 균열 좌표계를 매 반복마다 현재 주변형률 방향으로 돌리고(방향별 손상 d1·d2 는 주축 순서로 기록), 전단강성은 공축 조건 G_ij = (σi − σj)/2(εi − εj) 로 정함 (β 입력 무시). 고정 균열은 처음 ft 를 넘은 순간의 최대 주응력 방향을 균열 법선으로 고정하고, 균열 법선 강성만 (1−d) 로 줄이며 균열면 전단에는 잔류계수 β (기본 0.2, 손상이 커질수록 β 로 수렴) 를 적용. 균열면 안의 인장이 다시 ft 를 넘으면 직교 2차 균열. 3D 뷰에 균열 방향선 표시, 요소 클릭 시 균열 각도.
  - 300×500 3-D22 3점(L 3 m): 요소 125 mm → 등방 1.22, 고정 1.35 (β 0.2) / 1.31 (β 0.01), 회전 1.29; 요소 80 mm → 등방 1.20, 고정 1.20, 회전 1.16. T형 4점(L 6 m, 200 mm): 등방 1.17, 고정 1.17, 회전 1.15. 거친 메시에서 고정 균열이 더 강하게 나오는 것은 균열 요소의 연직·전단 강성이 남기 때문 (등방성은 모두 잃음).
