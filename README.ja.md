## 研究室への配布（スマートフォンアプリ / プログラム）

`python3 build_dist.py` を実行すると `dist/` に配布用ファイルができる（ExcelJS を内蔵した単一 `index.html` 約 1.2 MB + PWA マニフェスト・サービスワーカー・アイコン）。アーティファクト専用の保存機能の代わりにブラウザ標準のダウンロードを使うので、どこでも Excel・JSON・報告書・PNG の保存ができる。`rc-capacity-app.zip` は `dist/` をまとめたもの。

3 つの方法:
1. **ファイルで渡す（最も簡単）**: `dist/index.html` を 1 つ、LINE・メール・USB で送る。PC はダブルクリック、iPhone はファイルアプリから Safari で、Android は Chrome で開く。インターネットなしでも動く（フォントだけ標準フォントになる）。
2. **Web アドレスで共有 + ホーム画面アプリ（推奨）**: **https://hyonnnnnn.github.io/rc-capacity/** に公開済み（リポジトリ https://github.com/hyonnnnnn/rc-capacity、`gh-pages` ブランチ = `dist/`）。更新: `python3 build_dist.py` → `git add -A && git commit -m "..." && git push` → `git subtree push --prefix dist origin gh-pages`。研究室のメンバーはこのアドレスをスマートフォンで開き「ホーム画面に追加」（iPhone: 共有ボタン → ホーム画面に追加、Android: メニュー → アプリをインストール）を押すとアプリアイコンから起動でき、サービスワーカーがキャッシュするのでオフラインでも開ける。新版は `build_dist.py` を再実行してファイルを上げれば次回起動時に自動更新。
3. **Claude アーティファクトのリンク**: https://claude.ai/artifact/F4ZSJfPxLxHixJozJtna7R を Share メニューで共有。受け取る側にも Claude アカウントが必要。

### パソコン用プログラム（ダブルクリックで実行）

`app.py` が `dist/index.html` をシステムの WebView ウィンドウに表示するデスクトッププログラムで、PyInstaller でまとめるとインストール不要の実行ファイルになる。保存ボタンは OS の保存ダイアログにつながる。
- macOS: `sh build_app.sh` → `release/RC내력계산기.app`（この Mac でビルド・起動を確認、約 25 MB）。署名がないので初回に「開発元を確認できません」と出たら Finder で右クリック → 開く（またはターミナルで `xattr -dr com.apple.quarantine "RC내력계산기.app"`）。
- Windows: Python をインストールしてから `build_app.bat` をダブルクリック → `release\RC내력계산기.exe`（単一ファイル、WebView2 ランタイムは Windows 10/11 に標準搭載）。Windows 用は Windows でビルドする必要がある。
- 開発中にすぐ表示: `.venv/bin/python app.py`。ページを修正したら `python3 build_dist.py` を再実行。
- 実行ファイル内の index.html はビルド時点のコピーなので、計算機を更新したらプログラムも再ビルドして配布。

注意: 3D FEM はスマートフォンでも動くが、「細かい」要素寸法は PC を推奨。サービスワーカーは https（または localhost）でのみ登録される。

## 複合断面（合成材料層）

入力の「合成材料層」表に矩形の層を追加すると RC 断面に他材料を合成する（中心合わせ、上縁から y0・厚さ t・幅 w、コンクリートと重なる部分は置換）。矩形・T形・ボックスで使用可。
- 材料: 鋼板（fy, Es、弾性–完全塑性）、UHPC（f′c, Ec; 圧縮 0.85f′c 平坦、引張 ft = 0.23f′c^(2/3) 平坦 ~0.005）、FRP シート（Ef, ffu; 引張のみ、破断後 0）。
- 耐力: 層があれば Mu（正・負）と M–N 相関図をファイバー断面解析（設計強度、軸力 11 段階）で求める。せん断・βn・使用性・はり要素解析（EI は換算断面）・Excel の数式は RC 式のまま（Excel は値のみ記録）。
- 3D FEM: 層境界をメッシュ分割点に入れ、要素ごとに材料を割り当てる。鋼要素は von Mises 割線塑性、FRP 要素は最大主応力 > ffu で破断、UHPC は固有の f′c・Ec・ft の損傷モデル。支圧板は支点・載荷点で要素寸法の厚さ（薄い層の上のコンクリートまで）。
- ずれ止めすべり（3D、「鋼材層の接合」選択）: 鋼材層が独自の節点を持ち、コンクリートと同じ位置の節点対を境界面ばねで接続。x 方向は Ollgaard (1971) のスタッド荷重–すべり Q = Pu(1 − e^(−0.709s))^0.4 の割線剛性（列あたり本数/間隔 × 分担長、列の節点対に均等配分、更新減衰 0.6）、y・z は剛結（浮き上がりなし）。結果: 最大すべり・Q の行、Q–s リアルタイムグラフ、Excel 列。Pu を非常に大きくすると完全合成と同じ曲線（検証: 1e6 kN → 各ステップの荷重が一致）。300×500 + 下縁鋼板、3 点 L 3 m: Pu 90 kN・間隔 150・2 本 → 7 mm で 300 kN（完全合成 455）、すべり 0.8 mm; Pu 30・300・1 本 → すべり 2.4 mm、Q が Pu に収束。
- 検証（300×500 3-D22、γ = 1）: 下縁鋼板 300×12（fy 325）→ Mu 589 kN·m（塑性手計算 ≈ 600）、UHPC 上部 60 mm（f′c 150）→ 175（RC 166）、FRP 300×1.2（Ef 230 GPa、ffu 3000）→ 421（コンクリート圧壊支配）。3D 3 点 L 3 m 16 mm まで: 鋼板 489 kN（上昇中）、FRP 315（破断後 175 に低下）、UHPC 313（RC 269）。

## OpenSees ファイバー解析（`beam_fiber_opensees.py`）

- 入力: ファイル冒頭の `P` 辞書（計算機と同じ単位 mm, N/mm²）。矩形は `bf=b, hf=0`。
- 計算機の「入力 JSON 保存」で得たファイルを引数に渡すとそのケースで実行: `.venv/bin/python beam_fiber_opensees.py Beam-01.json`（矩形・T形のみ、2 段配筋は加重平均の深さにまとめる）。
- 結果 `out/beam_fiber.csv` は計算機の「実験データ比較」にそのまま読み込み、3D 解析・実験と重ねて見られる。
- 材料: Concrete02（ε0 = 2f′c/Ec、ft = 0.23 f′ck^(2/3)、残留 0.2f′c）、Steel02（ひずみ硬化 0.5%）。
- 出力: `out/beam_fiber.csv`、`out/beam_fiber.png`。コンソールに初期剛性（換算断面はり理論との比較）、ひび割れ・降伏・終局荷重、等価応力ブロック Mu との比。
- 検証値: 300×500 3-D22 矩形 → 最大 170.5 kN（Mu 換算 165.8 kN、比 1.03）。T形 6-D22+2-D16 → 355.7 kN（比 1.06、ε′cu 未到達）。

## Abaqus モデル（`abaqus_rc_beam_inp.py`）

- C3D8R コンクリート（強化砂時計制御）+ T3D2 鉄筋（主鉄筋・スターラップ）`*EMBEDDED ELEMENT`。
- CDP: 膨張角 36°、偏心 0.1、fb0/fc0 1.16、K 0.667、粘性 0.0005。圧縮は放物線+下降線、引張は GFI（Gf = 73 fcm^0.18 N/m）、損傷変数を含む。
- 支点: 下縁節点線のピン・ローラー。載荷: 上縁節点線の強制変位。結果: ヒストリー RF2（載荷点）、U2（中央下縁）。
- 解析: `abaqus job=rc_beam input=out/rc_beam.inp cpus=4 interactive`
- 収束しない場合: `viscosity` を 0.001 に、`es` を 40 に、`target_disp` を小さくする。
- このフォルダでは Abaqus を実行できなかったため、入力ファイルの構造のみ検証済み（節点・要素参照、材料表の単調性、鉄筋位置）。

## 3D 非線形 FEM（`rc-capacity.html` 内）

ブラウザ内で動く教育用の簡略モデル。ひび割れの広がりと荷重–たわみ曲線の形を見る用途。定量比較は OpenSees か Abaqus で。
- テスト（30×6×2 メッシュ）: 最大荷重 / 等価応力ブロック Mu 換算 = 3 点 1.27、4 点 1.09、6-D22+2-D16 0.99、40×8×4 3 点 1.17。
- 主鉄筋の付着選択: 完全付着（既定）/ 付着–すべり（良好・不良）。すべりモードでは主鉄筋（引張・圧縮）が列ごとに専用の x 自由度を持つトラスになり、各節点が fib MC2010 引抜き型の付着応力–すべり則（τ = τmax(s/s1)^0.4 → 平坦 → s3 で 0.4τmax; 良好 τmax 2.5√f′c, s1 1.0, s2 2.0 / 不良 1.25√f′c, 1.8, 3.6; s3 ≈ 0.5φ）の割線ばね（周長 × 分担長）でコンクリートに接続される。両端はフック定着とみなして強いばね。スターラップは完全付着のまま。鉄筋自由度はバンド幅のため該当列のコンクリート節点の直後に挿入（順列）。結果: 最大すべり・付着応力の行、τ–s リアルタイムグラフ、Excel ステップ表のすべり・τ 列。
  - 300×500 3-D22 3 点（125 mm、20 mm まで）: 完全付着 1.22 → 良好 1.19（最大すべり 0.15 mm、τ 6.4）、不良 1.29（すべり 0.42 mm、τ 3.8）。完全付着の結果はすべりコード追加前と同一（順列の検証）。
- ひび割れモデル選択: 等方性損傷（既定）/ 固定ひび割れ / 回転ひび割れ。回転ひび割れはひび割れ座標系を反復ごとに現在の主ひずみ方向に回し（方向別損傷 d1・d2 は主軸順で記録）、せん断剛性は共軸条件 G_ij = (σi − σj)/2(εi − εj) で定める（β 入力は無視）。固定ひび割れは初めて ft を超えた瞬間の最大主応力方向をひび割れ法線に固定し、法線剛性のみ (1−d) で低減、ひび割れ面のせん断には残留係数 β（既定 0.2、損傷が大きいほど β に収束）を適用。ひび割れ面内の引張が再び ft を超えると直交する 2 次ひび割れ。3D ビューにひび割れ方向線を表示、要素クリックでひび割れ角度。
  - 300×500 3-D22 3 点（L 3 m）: 要素 125 mm → 等方 1.22、固定 1.35（β 0.2）/ 1.31（β 0.01）、回転 1.29; 要素 80 mm → 等方 1.20、固定 1.20、回転 1.16。T形 4 点（L 6 m、200 mm）: 等方 1.17、固定 1.17、回転 1.15。粗いメッシュで固定ひび割れが強く出るのは、ひび割れ要素の鉛直・せん断剛性が残るため（等方性はすべて失う）。
